# Learning path: from a 3D-printed prototype to an engineered robot

This course uses one real robot, a planar **3-RRR parallel manipulator** driven by three hobby servos and steered with an MPU6050 IMU, to cover what a robotics engineer needs from CAD to controller. Every equation is implemented in [`pm3rrr_core`](../../ros2_ws/src/pm3rrr_core/pm3rrr_core), every figure is generated by [`analysis/generate_figures.py`](../../analysis/generate_figures.py), and every claim is checked by a unit test or a simulation.

## Prerequisites

* Linear algebra (vectors, 2×2 and 3×3 matrices, determinants), basic trigonometry
* Python with numpy; matplotlib for the figures
* For lessons 03 and 12: basic ROS 2 (nodes, topics, launch files)

## How to study each lesson

1. Read the theory and the figure.
2. Open the matching function in `pm3rrr_core` and find each equation in the code.
3. Run the snippet at the end of the lesson and change the numbers.
4. Do the exercises. Each one includes a hint, and its answer can be checked with the library.

```bash
pip install -r requirements.txt                    # numpy, matplotlib, mujoco, trimesh, ...
python3 analysis/generate_figures.py               # all lesson figures
python3 -m pytest ros2_ws/src/pm3rrr_core/test     # the maths, tested
```

## Notation used everywhere

| Symbol | Meaning | Value / unit |
|---|---|---|
| $\mathbf{x} = (x, y, \varphi)$ | platform pose: centre position and orientation | m, m, rad |
| $B_i$ | motor (servo) axis of leg *i* | on a circle $R_b$ = 87.5 mm |
| $A_i$ | elbow of leg *i* | — |
| $C_i$ | platform joint of leg *i* | on a circle $r_p$ = 26 mm |
| $\mathbf{c}_i$ | $C_i$ expressed in the platform frame | — |
| $l_1, l_2$ | proximal (motor) link, distal link | 50 mm, 50 mm |
| $\theta_i$ | absolute angle of the proximal link (actuated) | rad |
| $\sigma_i = \pm 1$ | working mode (elbow branch) of leg *i* | — |
| $q_i$ | URDF motor joint value, $q_i = \theta_i - \theta_i^{home}$ | rad, 0 = servo at 90° |
| $\mathbf{J}_x, \mathbf{J}_q$ | Jacobians, $\mathbf{J}_x\dot{\mathbf{x}} = \mathbf{J}_q\dot{\boldsymbol\theta}$ | — |
| $\kappa$ | condition number of the (homogenised) inverse Jacobian | 1 = ideal |
